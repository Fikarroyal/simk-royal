# SIMK Royal

Sistem Informasi Manajemen Kasir untuk kafe dan restoran yang membantu mengelola transaksi, stok, produk, pelanggan, karyawan, laporan, reservasi, pembayaran, hingga operasional bisnis dalam satu aplikasi. Mendukung 24+ fitur CRUD, pembayaran Midtrans, serta dapat digunakan secara offline melalui web/PWA maupun dikembangkan menjadi aplikasi Android (.APK) dan desktop Windows (.EXE), Mac (.DMG), serta Linux.
